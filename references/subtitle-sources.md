# 韩语字幕来源备选

按剧种/来源选路线，不必逐站走完。站点覆盖和版权政策会变化，每次都要核对剧名、年份、季数、集数和**韩语原文字幕**内容；只保存精选例句用于个人学习。本技能只提取韩语词条，绝不用翻译字幕反推韩语词汇。

## 韩剧 / 韩影（韩语原声 + 韩语字幕）

1. **KBS / MBC / SBS / tvN / JTBC**：韩国五大广电与有线台，剧名常用韩文原名 + SxxExx 搜索。公开节目与部分历史剧集提供韩文字幕（자막）。
2. **Netflix 韩剧**：如 *Squid Game*、*The Glory*、*Sweet Home*、*Moving*、*All of Us Are Dead* 等。若用户提供 Netflix 页面或本地韩语字幕文件，优先使用用户可访问的韩语原字幕；登录、地区限制或 DRM 导致无法读取时，不能假装已拿到台词，请用户贴字幕文本或上传 `.srt/.vtt/.ass/.smi`。
3. **韩国电影**：如 *Parasite*、*The Handmaiden*、*Oldboy* 等。用韩文片名 + `자막` / `SRT` 搜索。
4. **드라마 / 예능 / 웹툰**：如 *Vincenzo*、*Itaewon Class* 等，用韩文标题搜索。

## 韩语播客 / 新闻 / 教学（适合日常与考试词汇）

1. **YBM / 韩语听力教材**：YBM TOPIK 系列提供分级听力与文稿，适合 TOPIK 1–3 词汇。
2. **KBS 뉴스 / MBC 뉴스 / 연합뉴스**：新闻文稿为规范书面/口语韩语，适合 TOPIK 4–6 与学术韩语听力词汇。
3. **Slow Korean / KBS 韩语教学节目**：慢速韩语播客与教学节目，附文稿，适合初级 TOPIK 1–2 词汇。
4. **YouTube 韩语播客**：如 *Talk To Me In Korean*、*Korean Unnie* 等，用韩文标题搜索，转录文本可手动提取。

## 字幕数据库（兜底）

1. **OpenSubtitles**：<https://www.opensubtitles.org/>。把字幕语言设为 Korean/한국어，再按韩文剧名、年份、season/episode 过滤；多版本时以集数、分辨率/发行组和字幕行数判断是否对应目标视频。
2. **KoreanSubtitles.net / SubtitleHub**：韩语字幕社区，可用韩文片名搜索电影/剧集韩语 SRT。
3. **Subscene / YIFYsubs**：搜索时务必选择 **Korean** 语言标签，不要选 “Korean (English)” 之类的翻译字幕。

## 通用处理

- 已知站点的单集正文可以通过 `https://r.jina.ai/` 预处理，但先确认原页面真的含连续韩语对白；代理返回导航页、验证页或错误页时立即放弃该候选。
- 用户提供字幕文件时直接解析，不再联网。支持 `.srt`、`.vtt`、`.ass`、`.ssa`、`.smi` 和纯文本台词；先去时间码、标签和重复行，再保留韩语对白。
- 韩语特殊字符（아–ㅎ、声调符号等）必须保持原样，不做 ASCII 化；韩语无词内空格，提取时按原句实际词形填 `targets`（如 `자신감` → `["자신감"]`，若句中拆为多词则填全部片段）。

## 成功判断与止损

成功必须同时满足：

1. 页面或文件身份匹配剧名、年份、季数和集数；
2. 内容是韩语连续对白，或字幕文件包含时间码和韩语对白行；
3. 能从中抽出多条不重复的完整韩语原句。

HTTP 200、页面字数多、搜索摘要或剧情简介都不算成功。请求使用 `--connect-timeout 8 --max-time 20 -fL`；每个站点最多换一次搜索词，最多尝试三类来源。所有下载和引用都遵守站点条款与版权边界，不下载整集视频，不绕过登录、付费或地区访问控制。
